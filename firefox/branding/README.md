# Linden brand assets

linden-drop.svg is the original Linden mark: a simple droplet silhouette in restrained champagne/antique gold. It is intentionally understated, with no neon glow or wordmark dependency.

Use this asset for the browser icon, installer icon and start-page identity. For a production Windows application icon, export platform-specific ICO/PNG sizes from this SVG and include them in the Firefox branding build.
